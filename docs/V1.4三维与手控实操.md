# V1.4 三维仿真与手控实操

维护日期：2026-10-03。运行记录按实际日期保存。

## 1. 先跑一遍动画（约2分钟）

1. 启动项目，打开“运行与调度”。已有账户登录，首次使用先注册。
2. 分拣选择“正常分拣”，再选分拣任务；无人机选择风场场景和机型模型。
3. 点“自动仿真”。对应的传送带或无人机动画自动播放，参数和结果保存到当前账户。
4. 点暂停、拖动时间轴或点事件卡片，检查该时刻的位置、控制状态和反馈。可切换全景、跟随、俯视、自由观察；鼠标拖动与滚轮可旋转、缩放。
5. 在运行记录中点一次运行重新播放，点击“回放数据”下载完整时序；“保存画面”下载PNG，“录制动画”生成WEBM或浏览器支持的MP4。

仿真计算速度与动画播放速度分别设置。自动仿真即使很快计算完，仍按原始时间播放完整过程。暂停只暂停画面；停止计算或结束手控使用右侧按钮。手控模式默认紧跟最新服务器采样。

## 2. 无人机手控（约2分钟）

1. 选稳定风、机型和速度上限，点“开始手控仿真”。
2. 点三维画面，让键盘焦点进入场景。W/S向北/南、A/D向西/东、E上升、Q下降、J/L改变朝向；这里是局部ENU平移指令。
3. 触屏可拖左侧摇杆平移，按住右侧↑/↓升降。松开回中，焦点离开或页面隐藏会清除键盘/触屏输入。
4. 如有USB手柄或能输出HID的遥控器，勾选“USB手柄/HID遥控器”，按一个设备按钮激活识别。进入“通道设置”，逐轴检查左右、前后、升降、朝向，设置反向与回中死区并保存。
5. 点“结束手控并保存”。历史记录保存轨迹、原始轴输入、机型、结束原因、风场、电量与事件；原始ZIP的CSV保留manual_axes和heading_rad。

输入通信超过0.5秒未更新时回中；超过2秒结束会话。围栏、电量、风速、观测中断或碰撞触及限制时保存安全中止原因。手控会话最长取配置时长与300秒的较小值。结束手控的状态为STOPPED，不计为自主任务完成。

USB映射支持轴0至15、每轴反向与0.02至0.50死区。航模Mode 1、Mode 2按设备实际输出重新映射；软件不依据遥控器外壳或品牌猜测通道次序。

## 3. 分拣手控（约2分钟）

1. 选分拣任务、4至80件物料及故障场景，点“开始手控仿真”。
2. 双出口场景按A/B选择出口，再按空格逐件上料；也可点“上料A/上料B”。四出口场景按A/B/C/D或点1/2/3/4出口按钮。
3. 等当前物料有确认结果后再上下一件。正在输送时重复上料会提示拒绝，避免同时放行多件。
4. 遇到故障锁定，核对未知结果，勾选已清空仿真通道，点“确认恢复仿真”。动画保留卡料、错误出口与安全停止过程。
5. 用完点“结束手控并保存”；处理完配置的全部物料后也会自动封存结果。

手柄按钮0可单件上料；按钮1选择第二出口，四出口场景的按钮2/3选择第三/第四出口。未连接手柄时，键盘与触屏保持可用。

## 4. 六种分拣任务

| 任务 | 当前判据 | 场景中的工位 |
|---|---|---|
| 双出口传送带 | 任务中的0/1出口 | 传送带、放行闸门、换向、A/B出口光电 |
| 颜色识别 | 生成物料的red/blue属性 | 顶部识别工位、红蓝物料 |
| 尺寸分级 | 宽度50mm阈值 | 尺寸检测工位、大/小件模型 |
| 称重分级 | 180g阈值 | 称重工位、轻重物料 |
| 扫码四出口 | 物料编号映射至0至3 | 扫码工位、四支路与箱位 |
| 合格与重检 | 合格/待重检属性 | 质量复核和分流工位 |

上述分类字段由可复现种子生成，自动分类结果参与控制任务和出口统计。颜色、尺寸、重量与条码数据采集的实物接口尚待标定。当前STM32固件为A/B双出口，四出口软件场景按两组控制通道映射；四出口实体装置需要扩展状态机、协议和执行器I/O。

这六种任务可与正常、卡料、错出口、漏检、重复上料、传感器粘连、通信中断、急停、重启、重复命令组合。故障数据的“未知结果”与“确认完成”分别保存。

## 5. 八种无人机结构模型

| 模型 | 可见结构 |
|---|---|
| 工业巡检四旋翼 | 四机臂、旋翼、起落架、云台 |
| 便携折叠四旋翼 | 紧凑机体、折叠式机臂外观 |
| 轻型迷你四旋翼 | 小尺寸轻型机体 |
| FPV穿越机 | 深色机架、紧凑旋翼布局 |
| 带桨保护圈航拍机 | 四个桨保护圈 |
| 工业六旋翼 | 六机臂、六旋翼 |
| 重载八旋翼 | 八机臂、八旋翼 |
| 共轴X8 | 四机臂、上下共轴八旋翼 |

所有模型使用当前项目的三维质点飞行计算，位置和风速来自完整原始采样；自主飞行朝向由轨迹估算，手控朝向来自保存的输入。机型选择用于结构显示，不改变为某厂商经标定的气动、姿态或电机模型。电力塔与导线为场景背景，参与碰撞判定的区域来自配置中的obstacles。

## 6. 连续对照、导出和数据保留

- 点“配对基准实验”运行相同种子的不同策略，结果页可逐场播放，也可“连续播放全部3D”，播放器提供上一场/下一场。
- 回放JSON含完整帧、配置、结果、事件、运行编号及SHA-256。哈希对应UTF-8、排序键、紧凑分隔符的replay对象。
- 动画录制保存当前相机画面，单次最多60秒，已保存动画播完自动结束录制；选择较快回放速度可录完整较长任务。画面与回放数据承担不同用途。
- LD-Flex保留事件链、motion_batch、原始运行ZIP；巡检保留完整原始轨迹和任务ZIP。旧分拣记录只有状态时，界面显示“旧记录/状态动作”，不补造物料位置。
- 日常数据仍保存在既有data或运行结果目录，账户之间隔离。三维静态资源已随源码保存，本机不依赖3D CDN。实机记录未测量连续位置时，使用信号回放核对反馈。
