# V1.3 实验工作区实操

维护日期：2026-10-03。启动后默认进入新的个人工作区。首次使用先注册；已有账户直接登录。菜单中的“专业控制台”保留设备操作与详细信号分析。

## 1. 完成一次有结论的实验

1. 点击“新建实验”，填写名称和目的，选运行场景、随机种子、参数及可选设备。
2. 打开计划详情，核对参数并勾选确认，点击“确认参数”。
3. 点击“执行仿真”。LD-Flex 在运行中心显示过程，巡检系统计算航线与风扰反馈；结果自动关联到计划。
4. 到“数据与对照”，从已封存运行提取完整采样。实际 CSV 可按页面表头导入，并选择数据来源。巡检轨迹导入时选 ENU 或 NED，核对共同原点与米制单位。
5. 选择两组不同数据计算报告。在实验详情关联数据和报告，填写实际复核结论，点击“保存结论并归档”。
6. 报告中心可以查看、打印并保存 PDF；“实验包”下载参数、时间线、关联的原始运行、数据和报告，附 SHA-256 清单。

实验状态是草稿→已核对→运行中→待复核→已归档。参数未核对不能执行，运行中的实验不能移至归档记录。运行结束后仍需人工复核，不自动给出合格结论。

## 2. 数据对照

| 系统 | CSV 表头 | 比较方法 |
|---|---|---|
| LD-Flex | time_s,job_id,cycle_s,route,outcome | 唯一物料编号、相同出口配对；仅计算均已确认完成的周期 |
| 风巡智航 | time_s,x_m,y_m,z_m | 局部 ENU 坐标，显式时间偏移与限间隔线性插值，不外推 |

物料出口 route 为0或1，outcome 为 completed 或 unknown。CSV 使用 UTF-8，文件不超过750 KB，最多20000行。巡检轨迹时间严格递增。误差报告包括 RMSE、MAE、P95 和有效配对数；排除规则、数据编号与摘要随报告保存。

原生运行提取的数据保留完整采样；界面绘图可抽样。演示数据、原生仿真、用户标注的导入和本机设备记录保留各自的来源。对照计算只描述输入数据之间的差异。

## 3. 设备与校准

登记型号、资产编号、接口和接线备注。按同一测量项、单位录入参考值、观测值与容差，保存测量条件与有效期。软件计算观测减参考的偏差和是否超过容差；超限或过期会产生通知。演示测试请选“演示数据”。

LD-Flex：点击“打开本机实物连接”，进入 USB 串口控制台。应先完成接线、电平、急停和舵机行程核对；本机操作员权限、通道确认和板上确认继续由设备会话执行。登记设备档案不会启动装置。连接蓝牙串口不代表连接到STM32。

风巡智航：当前以轨迹 CSV 对照实测；型号确定后再实现飞控数据适配。资产与缺陷页支持资产登记、关联已保存任务、人工复核和工单流转。

## 4. 日常操作

- Ctrl / Cmd + K：按名称、编号或状态查找实验、设备、参数模板、运行、数据和报告。
- 收藏：在实验、设备或数据旁设置星标，进入“我的收藏”再次打开。
- 运行页：保存当前参数为模板，下次点击模板应用。
- 实验计划：切换看板/列表、按名称与目的筛选；移至归档记录后可勾选“显示归档记录”恢复。
- 设置：切换浅色/深色和信息密度，更新显示名称及邮箱，下载完整个人备份。

## 5. 本地记录与恢复

新功能为每个账户增加 studio.sqlite3，记录实验、设备、模板、操作时间线和偏好。既有运行数据库不改表，账户隔离继续使用个人目录和服务器会话。日志记录实际运行时间；旧材料中的开发完成日期与本次维护日期分开保存。

本次升级前的数据库快照与逐表摘要保存在项目的本地证据目录，Git 不包含真实账户库和运行数据。恢复数据库前先停服，保留当前副本，再恢复目标账户对应的文件；不要在运行中覆盖数据库。

如果执行请求后服务突然退出且实验没有运行编号，超过5分钟会进入待复核。应先从运行记录确认是否已经执行，再关联封存结果，避免重复启动。

## 6. 系统支持和测试边界

服务核心为 Python，界面使用浏览器；图标等静态资源已随源码保存，本机运行不依赖图标 CDN。LD-Flex 仿真需要本地 C 编译器构建共享库。源码包含自动验证工作流，跨系统构建结果以对应提交的 CI 结果为准。

当前已在 Windows 本机进行账户、实际仿真、数据导入对照和页面验证。手机宽度验证用于响应布局，不等于已完成手机安装包。实体装置、飞控、跨系统安装包的验收单独进行。
