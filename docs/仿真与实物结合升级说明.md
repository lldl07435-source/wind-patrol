# 仿真与实物结合：V1.2 使用与升级路线

本次维护按实际日期记录。历史 V1.0 申请材料与开发完成日期单独保留。

## 已完成的实验流程

1. 运行一次仿真，或结束并封存一次设备会话。
2. 打开导航中的“仿真与实测实验中心”，从原始运行导入完整采样。
3. 添加另一组数据，设为基准和对照，计算误差。
4. 在历史报告中查看结果，下载 JSON；数据集可下载 ZIP。

实验库使用当前账户工作区的 `experiments.sqlite3`。原有数据库与运行记录继续保留。
数据集创建后不原地修改；重采样或更换条件时新增一组，便于追溯。
导入文本摘要和标准化数据摘要分别记录，CSV 文件经浏览器解码成 UTF-8 文本后保存；不声称保留上传文件的字节级编码特征。
CSV 导入最多 750 KB、20000 行；每账户最多 200 组实验数据、500 份对照报告，并受工作区容量限制。
图表超过1000点时抽样，计算与下载使用完整数据。采样回放显示当前时间附近的观测点，曲线不是实时控制命令。

## 数据来源

| 标注 | 含义 |
|---|---|
| 原生仿真 | 从该账户的软件仿真结果导入 |
| 本机设备记录 | 从已封存、校验通过的本机串口记录导入 |
| 实测导入（用户标注） | 用户声明来源的 CSV，不自动鉴别真实性 |
| 仿真导入（用户标注） | 外部模拟软件生成的 CSV |
| 接口演示数据 | 用于验证界面和格式的构造样例 |

## 多风巡检：轨迹与遥测数据对照

### 先验证数据入口

1. 在运行控制台选场景，执行一次巡检仿真。
2. 实验中心导入这次任务的完整轨迹。
3. 导入外部CSV，确认单位与坐标原点、轴向，再选基准和对照。
4. 如需对齐，填写明确的时间偏移；调整最大可插值间隔，计算并保存。
5. 查看有效覆盖率、跳过点数、三维位置误差和各轴偏差。

CSV 表头：`time_s,x_m,y_m,z_m`，时间为秒、位置为米。
NED导入会将北/东/下换为东/北/上，即ENU=(NED.y,NED.x,-NED.z)。
仿真x/y/z属于局部模型坐标。轴变换不会自动解决GPS投影、不同起点、不同航向或安装误差；实际对照前必须完成原点和轴向核对。
时间偏移加到对照时间上。只在线段有效时间范围内插值，不外推；超过最大插值间隔的点跳过。
RMSE/MAE针对三维位置差，不等同于抗风控制性能或缺陷识别精度。

目前支持离线轨迹数据接入，未实现PX4/ArduPilot直连、解锁、航点下发或在线飞行控制。
下一步飞控接入建议先实现只读LOCAL_POSITION_NED遥测并保留消息时间和掉包记录，之后再做硬件在环。
字段与坐标约定依据：[MAVLink 官方消息定义](https://mavlink.io/en/messages/common.html#LOCAL_POSITION_NED)。


## 界面检查结论

旧流程已实际打开检查：仿真入口与人工记录页面分散，空状态占据较多面积；设备反馈需要阅读原始JSON。
新流程把数据来源、曲线、指标、导入、库与报告放在一个工作空间，并提供移动宽度布局和可见键盘焦点。
本次浏览器验收实际执行：原生仿真采样导入、演示CSV保存、数据选择、计算、历史报告、刷新与下载。
当前截图和界面实验属于本次维护验证，不代替实物测试。完整无障碍合规未在本次认定。

## 下一阶段的优先级

| 阶段 | 交付内容 | 完成依据 |
|---|---|---|
| P0 已实现 | 数据接入、误差分析、按账户保存、报告导出 | 自动测试和实际浏览器流程 |
| P1 实物台架 | 接线与固件核验、两路各30件、急停/卡料/失联恢复 | 原始设备日志、测量条件和视频 |
| P2 参数标定 | 建模周期与实测周期的差异，确认稳定清空时间与换向时间 | 独立标定组和验证组，保留未配对/未知数据 |
| P3 控制器在环 | 实验台输入、STM32控制逻辑、状态回传和仿真对照 | 真板运行记录；测试用串口替身不计入这一阶段 |

预算优先用于 LD-Flex 台架。现有软件升级没有新增付费服务或运行依赖；未购买任何硬件。
多风巡检先做模型与遥测数据验证，真实飞行还需要设备、场地和实际飞控适配。
