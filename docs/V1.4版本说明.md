# V1.4.0 三维仿真升级说明

维护日期：2026-10-03。

## 功能

1. 分拣增加六种任务及完整产线模型：皮带、滚筒、电机、闸门、分流、箱位和识别工位。分类字段参与真实任务路由和统计。
2. 无人机增加八类结构模型、旋翼动画、电力环境、航点、风矢量、原始轨迹和安全事件；全量采样驱动动画。
3. 加入键盘、触屏、Gamepad/HID手控，账户独立保存16轴映射、反向和死区，服务器固定步长执行与安全终止。
4. 加入全屏、视角、时间轴、事件定位、历史回放、配对连续播放、PNG、动画录制和带摘要的完整回放JSON。
5. 离线保存Three.js0.186.1与MIT许可证，保留旧二维与专业控制台入口。登录、CSRF、权限和数据隔离继续在服务器执行。

## 本地验证

两项目各93项Web测试：分拣91通过、2跳过；巡检90通过、3跳过。跳过项为领域不适用的接口。9项时序语义检查全部通过，覆盖帧去重、故障停止、物料切换、信号时刻、边界和坐标转换。真实页面的运行、手控、场景、导出与响应布局记录保存在本地证据目录。

后续CI结果应以本次公开提交的完整SHA为准。硬件、厂商SDK与飞控实测单独验收；本次验证为本地软件与浏览器仿真。
