# 遥控器及实机适配范围

核对日期：2026-10-03。

## 当前输入能力

| 输入方式 | 软件实现 | 设备验证状态 |
|---|---|---|
| 键盘与鼠标 | 已实现，场景焦点控制、回中、视角操作 | 本机页面已验证 |
| 触屏摇杆及升降键 | 已实现平移/升降及松开回中 | 浏览器中已实际拖动验证 |
| 标准USB或蓝牙游戏手柄 | Gamepad API读取设备、4个控制轴、死区和反向 | 等待真实手柄逐台验证 |
| USB Joystick航模遥控器 | 输入轴0至15可映射，支持Mode 1/Mode 2重新配置 | 等待遥控器及系统驱动验证 |
| PPM/SBUS等转USB-HID的模拟器适配器 | 使用适配器的浏览器Gamepad输出 | 需核对转换器与遥控器说明书 |
| 厂商专用遥控器 | 取决于能否输出标准Gamepad/HID或开放协议 | 尚无专用SDK适配 |

本软件当前只把这些输入用于仿真。判定能否使用的直接证据是浏览器能否列出设备和输入轴，而非设备品牌名称。

## 可优先核对的设备资料

RadioMaster TX16S的官方规格列出USB-C模拟器/电脑连接口；EdgeTX提供USB Joystick的经典与高级通道设置。其他EdgeTX遥控器先按其说明书确认USB Joystick模式。FrSky Taranis X9D+的地面站官方文档提供作为摇杆接入的说明。设备进入操作系统的Gamepad接口后，再使用本软件映射。

- [EdgeTX USB Joystick](https://manual.edgetx.org/color-radios/model-settings/model-setup/usb-joystick)
- [RadioMaster TX16S官方规格](https://radiomasterrc.com/collections/popular-products/products/tx16s-hall-radio-controller)
- [QGroundControl摇杆设置及Taranis示例](https://github.com/mavlink/qgc-user-guide/blob/master/en/SetupView/Joystick.md)
- [浏览器Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)

这是一份接入候选资料，不是本软件已经对这些实体设备完成兼容认证的名单。

## 设备到手后，完成一次可复核接入

1. 填设备厂商、型号、固件、系统版本和接口；确认使用数据线和正确USB口。
2. 让操作系统识别游戏控制器，启动仿真，勾选USB输入，按一个按钮激活。
3. 逐个拨动摇杆，记录四轴映射、反向、回中值和死区。先用稳定风及低速度验证。
4. 在仿真中测试移动、升降、回中、断开和页面失去焦点，核对服务器保存的manual_axes及结束原因。
5. 将设备名称、映射、原始运行ZIP、截图和失败情况保存在本地接入记录。再增加该型号的“已测试”标记。

## 实机连接路线

LD-Flex现有STM32 USB串口会话使用原生协议、校验、急停与确认流程。新增三维手控作用于仿真；真正操作装置继续从“本机实物连接”进入。四出口、皮带驱动、编码器、称重和扫码器需按实际I/O扩展并做台架验证。

巡检系统目前可导入有时间戳的ENU/NED轨迹CSV，与仿真做对照。PX4/ArduPilot的后续在线手控可围绕MAVLink MANUAL_CONTROL设计遥测桥接、心跳与失联处理，但当前源码没有发送该协议控制实体飞行器。

- [PX4摇杆及遥测链路](https://docs.px4.io/main/en/config/joystick)
- [MAVLink Manual Control协议](https://mavlink.io/en/services/manual_control.html)

厂商封闭协议、固定翼和垂直起降飞行器分别需要对应SDK及动力学。当前八类模型覆盖多旋翼的结构显示和当前质点仿真，未完成这些飞行器的物理适配。
